# WebFS

Консольный файловый менеджер для веб-сайтов: сайт представляется как виртуальная файловая система.

После подключения к сайту (`open`/`mount`) структура страниц и ссылок доступна для навигации привычными командами терминала (`ls`, `cd`, `pwd`, `tree`, `find`).

$ golangci-lint run ./...
$ go vet ./...
$ gofmt -l .
$ go build ./...
$ go test ./... 
$ go test ./... -tags=integration
$ go test ./... -tags=e2e
